# One Word From Grandma

An entry for make.fun's **One Word From Grandma** bounty: send exactly one word — the word your grandma would text about AI.

The word is **ALEXAAA**: grandma shouting at the talking box in the corner, holding the A key a beat too long because she isn't quite sure shouting helps, but she's going to try anyway. Warm, a little baffled, tied to an AI voice assistant, and funny with no caption at all.

## How it works

`main.py` (Python 3.13, standard library only, no network) writes exactly one word to `/output/entry.txt`:

```sh
python3 main.py
```

It self-checks the competition's gate first — one word, 1 to 30 characters, no white space — and fails loudly instead of shipping an entry the gate would refuse. Two runs write byte-identical output.
